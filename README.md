# WebsiteRater - A project for Deerhacks 2024
## 	<sub> Purpose: </sub> 
  The goal of this project is to be made for the submission of the Deerhacks 3 hackathon. 

## 	<sub> Installation:	</sub>
  1. Download the source files.
  2. Extract the source folder from the ZIP folder.
  3. Open the source files in VSCode (highly recommended).
  4. Open a new terminal and run pip install for beautifulsoup4, streamline, streamlit, and streamlit-lottie.
  5. To run the WebsiteRater site, run "streamlit run app.py" (without "") in the terminal.
